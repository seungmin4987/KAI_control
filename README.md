

# 코드 상세 설명 보고서

## 개요
본 코드는 ESP32를 기반으로 ROS 노드와 FreeRTOS를 사용하여 차량 제어 시스템을 구현한 프로그램입니다. 자율주행, 수동 모드, 비상 정지 모드(E-Stop)를 포함한 차량 제어 기능을 제공하며, PID 제어를 통한 차량 속도 조절 및 ROS 통신을 통해 제어 명령과 피드백 데이터를 송수신합니다. 주요 구성 요소로는 서보모터를 활용한 브레이크 제어, 모터 PWM 제어, 엔코더를 통한 속도 측정, 디스플레이 출력 등이 포함됩니다.

---

## 주요 핀 번호 정의
### 제어 핀
- **ESTOP_PIN_1 (27)**: 리모컨 E-Stop 버튼 핀.
- **ESTOP_PIN_2 (25)**: 폴링 방식 E-Stop 버튼 핀.
- **ASMS_MODE_PIN (33)**: 자율/수동 모드 전환 스위치 핀.
- **BRAKE_SERVO_PIN (26)**: 브레이크 서보모터 제어 핀.
- **MOTOR_PWM_PIN (5)**: 모터 속도 제어 핀.
- **ENCODER_PIN_A (18), ENCODER_PIN_B (19)**: 엔코더 신호 입력 핀.

### 디스플레이 핀
- **CLK (2)**: TM1637 디스플레이 클럭 핀.
- **DI0 (4)**: TM1637 디스플레이 데이터 핀.

---

## 상수 정의
- **BRAKE_START_ANGLE (85)**: 서보모터 초기 각도 (브레이크 해제 위치).
- **SERVO_MAX_ANGLE (120)**: 서보모터 최대 각도 (브레이크 최대 작동 위치).
- **DEBOUNCE_DELAY (150ms)**: 디바운스 처리 시간.
- **WHEEL_ROUND (1.57m)**: 바퀴 둘레.
- **control_time_interval (100ms)**: 제어 주기.
- **GEAR_RATIO (4.25)**: 기어비.
- **ENCODER_RESOLUTION (1024)**: 엔코더 펄스 수 (1회전당).

## 주요 함수 설명

### 1. **PID 계산 함수: `calculatePID`**
PID 제어 알고리즘을 구현하여 목표 속도와 현재 속도의 오차를 기반으로 출력값을 계산합니다.
- **입력**: 목표 속도, PID 상수(kp, ki, kd), PID 활성화 상태.
- **출력**: 계산된 PID 출력값.
- **동작**:
  1. 오차 계산: `g_error = target_speed - g_current_speed`.
  2. 적분 및 미분 항 계산.
  3. PID 출력 계산 및 PWM 범위로 제한.

### 2. **종방향 제어 함수: `longitudinalControl`**
차량의 속도를 제어하기 위한 종방향 제어 로직을 구현합니다.
- **입력**: 목표 속도, PID 상수.
- **동작**:
  1. PID 출력값을 계산.
  2. 양수 오차: 모터 PWM 제어.
  3. 음수 오차: 브레이크 제어.
  4. 비상 정지 시 브레이크 최대 작동.

### 3. **ASMS 모드 업데이트 함수: `update_ASMS_mode`**
ASMS 스위치 및 E-Stop 상태를 확인하여 차량의 현재 모드를 업데이트합니다.
- **입력**: 현재 시간, 디바운스 지연 시간.
- **동작**:
  1. 디바운스 처리 후 모드 확인.
  2. 자율, 수동, 비상 정지 모드 전환.

### 4. **속도 표시 함수: `displayFloatWithDecimal`**
TM1637 디스플레이에 현재 속도를 소수점 단위로 표시합니다.
- **입력**: 표시할 속도 값.
- **동작**:
  1. 속도를 정수 및 소수 부분으로 나눔.
  2. 디스플레이 인코딩 후 출력.

### 5. **브레이크 각도 계산 함수: `getBrakeAngle`**
브레이크 입력 값을 서보모터 각도로 변환합니다.
- **입력**: 브레이크 입력 값, 게인 값.
- **출력**: 계산된 서보모터 각도.
- **동작**:
  1. 입력값을 0~1로 정규화.
  2. 지수 함수를 사용해 각도를 계산.

## ROS 관련 설정
### ROS 노드 초기화 및 통신 설정
1. **노드 초기화**: `nh.initNode()`.
2. **토픽 구독**:
   - **control_topic**: `g_target_speed` 업데이트.
   - **pid_tuning_topic**: PID 상수 조정.
3. **토픽 퍼블리시**:
   - **mcu_feedback_topic**: 현재 속도와 E-Stop 상태 송신.

### ROS 메시지 콜백 함수
1. **`messageCb`**: 목표 속도 업데이트 및 PID 활성화.
2. **`pidTuningCb`**: PID 상수 업데이트.

---

## 동작 흐름
1. **모드 전환**:
   - **EMERGENCY**: 브레이크 최대 작동.
   - **AUTONOMOUS**: PID 제어.
   - **MANUAL**: PWM 해제 및 브레이크 해제.
2. **속도 계산**:
   - 엔코더 펄스 값으로 현재 속도 계산.
3. **ROS 통신 유지**:
   - 1초 동안 메시지 수신 없으면 목표 속도를 0으로 설정.
